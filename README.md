# Otimiza Lume

Organiza o armazenamento, libera espaço com segurança, envia arquivos antigos ao Google Drive e deixa o Windows mais leve,
de forma automática e sempre com como desfazer.

## Baixar

**[⬇ Baixar o Otimiza Lume 0.6.8 (OtimizaLume-Setup.exe)](https://github.com/rbarretoadvogada-wq/otimiza-lume-download/releases/latest/download/OtimizaLume-Setup.exe)**

Abra o arquivo baixado: ele confere o seu Windows, baixa o instalador certo para o seu computador, verifica a
integridade do arquivo e instala. O Windows vai pedir permissão de administrador.

## Requisitos

| | |
|---|---|
| Sistema | Windows 10 versão 1809 (2018) ou mais novo, ou Windows 11 |
| Processador | 64 bits: Intel/AMD ou ARM (ex.: notebooks Snapdragon) |
| Espaço | cerca de 400 MB |

Não funciona em macOS, Linux nem em Windows de 32 bits.

## Aviso do Windows ao baixar

Enquanto o instalador não tiver assinatura digital, o Windows pode mostrar **"O Windows protegeu o computador"**.
Para continuar, clique em **Mais informações → Executar assim mesmo**. Confira antes que o arquivo veio deste endereço.

## Instaladores avulsos

Para instalação sem internet ou em várias máquinas, baixe o `.msi` da sua arquitetura em
[Versões](https://github.com/rbarretoadvogada-wq/otimiza-lume-download/releases/latest): `-x64.msi` (Intel/AMD) ou `-arm64.msi` (ARM).

O Otimiza Lume se atualiza sozinho quando sai versão nova.
